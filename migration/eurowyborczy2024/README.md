# EuroWyborczy 2024 - migration artefacts (not for merge)

Everything in this folder belongs to the draft pull request of the migration and is meant to be
dropped (or moved to `pr-assets`) before anything is merged. The code of the migration is the
other commit: `src/constants/result-modules.ts`, `src/constants/survey.ts` and their tests.

## Files

| File | What it is |
| --- | --- |
| `quiz-data-eurowyborczy2024.json` | Output of `quiz-conversion-bot` for the slug `eurowyborczy2024`, untouched (step 2) |
| `screenshots/` | The result page of the migrated quiz at 1280 and 375 px, and a question |
| `mock/build-survey.mjs` | Turns the bot output into the survey and the project the new API would send |
| `mock/mock-api.mjs` | Local stand-in for the API: project, survey, creating and reading a result |
| `mock/e2e-run.mjs` | Takes the quiz from the home page to the result page in a headless Chrome |
| `mock/survey.json`, `project.json`, `ids.json` | Generated by `build-survey.mjs` |

## Run it

```bash
node migration/eurowyborczy2024/mock/mock-api.mjs        # http://localhost:4010
echo 'VITE_API_URL=http://localhost:4010/api' > .env.local   # git-ignored
yarn dev                                                 # then open /quizzes/eurowyborczy2024
```

## What is real and what is not

- **Real:** the title, the five categories, the 30 statements, the five ideologies (names, colours,
  logos) and the axis, all from the bot.
- **Placeholder - the scoring.** The bot leaves `possibleAnswers` empty for every question of this
  quiz (its type is `FOR_AND_AGAINST`, and the query asks only for `effects.custom`), so the app
  would drop all 30 questions and report the quiz as not found. The production GraphQL API has
  introspection switched off, so the real effects could not be looked up. `build-survey.mjs`
  therefore gives every question four answers and assigns them to ideologies by an illustrative
  table (`PLACEHOLDER_SCORING`). **The percentages on the result page come from that table, not from
  the old quiz.** It has to be replaced with the real weights.
- **Provisional identifiers.** The old ids are Mongo ids. The generated ones are deterministic and
  UUID-shaped, so reruns give the same ones; the API will assign its own when the quiz is imported,
  and `OWN_RESULT_MODULES`, `QUIZ_PROJECT_IDS` and the fixtures must be changed to match.
- The result is calculated by the mock with the algorithm of `mypolitics-survey-consumer`
  (`calculator.service.ts`), on the placeholder answers.
